# Titanic Survival Prediction

## Project Overview
This project uses the Titanic dataset to predict whether a passenger survived or not during the Titanic disaster. It is a beginner-friendly machine learning classification project that demonstrates data preprocessing, exploratory data analysis, feature engineering, model training, and evaluation.

## Objective
Build a machine learning model that predicts passenger survival based on features such as age, gender, passenger class, fare, and other relevant information.

## Dataset
The dataset contains information about Titanic passengers, including:

- PassengerId
- Pclass (Passenger Class)
- Name
- Sex
- Age
- SibSp (Number of Siblings/Spouses Aboard)
- Parch (Number of Parents/Children Aboard)
- Ticket
- Fare
- Cabin
- Embarked
- Survived (Target Variable)
