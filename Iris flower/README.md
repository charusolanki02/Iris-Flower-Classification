# Iris Flower Classification

## Objective
Classify Iris flowers into different species using Machine Learning.

## Dataset
IRIS.csv

## Algorithm Used
Random Forest Classifier

## Libraries Used
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Project Workflow
1. Load Dataset
2. Data Preprocessing
3. Train-Test Split
4. Train Random Forest Model
5. Evaluate Accuracy
6. Predict Iris Species

## Result
The model successfully classifies Iris flowers with high accuracy.
